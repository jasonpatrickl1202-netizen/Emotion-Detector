# 📸 Foto-Kita-Blur--python

This repository contains a desktop application built with **Python** inspired by the trending **"Foto Kita Blur"** aesthetic. This project allows users to easily load local images, apply a customized artistic blur effect, and save the edited results instantly.

## ✨ Core Features
* 🖼️ **Image Uploader:** Seamlessly open and load image files (`.jpg`, `.png`, `.jpeg`) from your computer.
* 🎛️ **Precision Blur Slider:** Real-time adjustment control to fine-tune the intensity of the blur effect.
* 💾 **Export & Save:** Save your processed aesthetic photos directly back to your local storage.
* ⚡ **Local Processing:** Fast image manipulation running entirely offline on your local machine.

## 🛠️ Built With
* **Python 3.x:** Core programming language.
* **Pillow (PIL) / OpenCV:** For robust image processing and applying blur filters (Gaussian blur).
* **Tkinter / PyQt:** For the interactive Graphical User Interface (GUI).

## 🚀 Getting Started

To run this Python application locally on your machine, follow these steps:

### Prerequisites
Make sure you have Python installed. Then, install the required dependencies:
```bash
pip install Pillow
```

### Installation & Execution
1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the Project Directory:**
   ```bash
   cd Foto-Kita-Blur--web
   ```
3. **Run the Application:**
   ```bash
   python main.py
   ```
